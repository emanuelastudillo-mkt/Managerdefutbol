# V9.33 · Ser jugador: ofertas por progresión

Base: V9.32.

- Se retiraron físico, moral y forma de la interfaz y de los cálculos del minijuego.
- El rendimiento se concentra en media, confianza, rol, nivel del club, adaptación, regularidad y presión.
- El mercado entrega entre dos y cuatro ofertas de clubes externos según la evolución de media y la reputación alcanzada.
- La calidad de los clubes escala con la carrera y prioriza instituciones mejores que el club actual.
- Se mantienen el historial anual, los trofeos individuales y el archivo de las últimas 20 carreras retiradas.
- El estado continúa aislado dentro de `game.miniGames` y no modifica la carrera principal del mánager.
