# V9.37 · Ser jugador: opciones destacadas y ficha compacta

Base: V9.36.

- Las opciones de eventos, mercado y clubes iniciales ahora se perciben claramente como botones interactivos.
- Se agregaron estados visuales de hover, selección, foco y pulsación.
- Las propuestas de renovación, clubes pequeños y clubes externos conservan tonos diferenciados.
- Las estadísticas principales redujeron tamaño, separaciones y altura.
- La Media, datos personales, PJ, goles, asistencias, estado de carrera y palmarés ocupan menos espacio vertical.
- Los trofeos individuales históricos también usan filas más compactas.
- No se modificó la lógica deportiva ni el guardado del minijuego.
